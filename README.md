 # Tableau-retail-sales-dashboard

Interactive Tableau dashboard analyzing retail sales, profit, and customer trends

## Overview
This dashboard analyzes retail business performance across regions, customer segments, and monthly order trends using the Superstore dataset. Built with Tableau Desktop as part of my data analytics learning journey (Udemy course).

## Key Insights
- Central and West regions drive the highest revenue contribution
- Segment-wise profitability visualized using stacked bar charts
- Scatter plot mapping sales vs. profit to identify outlier accounts
- Order quantity trends show a seasonal peak in May
